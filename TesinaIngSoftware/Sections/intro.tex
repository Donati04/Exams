\section{Introduzione}
Nei moderni sistemi web raramente un singolo servizio è responsabile della gestione di tutte le
richieste in arrivo: applicazioni frontend, API REST, servizi di autenticazione e risorse stati-
che sono spesso ospitati su processi distinti. Un reverse proxy si colloca all’ingresso di questa
infrastruttura, intercettando le richieste dei client e instradandole verso il servizio backend corretto,
nascondendo al client la reale topologia del sistema.
